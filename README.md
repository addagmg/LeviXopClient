# LeviXopclient
Fabric client mod for Minecraft 1.21.4.

Menu: Right Shift (rebind in Options > Controls > LeviXopclient). Fallback command: /lx
Tabs: Modules, Performance, Combat, Movement, Render, HUD, Misc, Profiles, Settings.
Tap a card to toggle, tap the small square (bottom right) for module settings + keybind.
HUD tab: "Remove HUD Background" and "HUD Editor".
Screen Recorder (Misc): turn ON to start. F7 pause/resume, F8 stop. Saves to .minecraft/recordings (MJPEG .avi, no audio).
Commands: /friend add|remove|list <name>, /wp add|del|list <name>
